LoveCats API

API pública e gratuita para integração com sistemas de adoção de gatinhos. Conecte seu site, aplicativo ou sistema de gestão à nossa plataforma.

Recursos da API

API RESTful

Interface REST padronizada com respostas JSON

Segurança

Autenticação via API Key e validação de dados

Alta Performance

Resposta rápida e cache inteligente

Informações validadas e atualizadas em tempo real

Fácil Integração

Documentação completa e exemplos práticos

Endpoints Disponíveis

Todos os endpoints retornam dados em formato JSON

GET /api/cats

Lista todos os gatinhos disponíveis para adoção

Parâmetros:

color ( string ) opcional

Filtrar por cor

sex ( string ) opcional

Filtrar por sexo (Macho/Fêmea)

age ( string ) opcional

Filtrar por idade

vaccinated ( boolean ) opcional

Filtrar por vacinação

neutered ( boolean ) opcional

Filtrar por castração

Resposta:

              
    {
      "id": "string",
      "name": "string",
      "age": "string",
      "sex": "Macho | Fêmea",
      "color": "string",
      "description": "string",
      "location": "string",
      "contact": "string",
      "photo": "string",
      "vaccinated": "boolean",
      "neutered": "boolean"
    }
GET /api/cats/:id

Retorna detalhes de um gatinho específico

Parâmetros:

id ( string ) obrigatório

ID único do gatinho

Resposta:

              
    {
      "id": 1,
      "name": "Miau",
      "color": "Laranja",
      "sex": "Macho",
      "age": "2 anos",
      "vaccinated": true,
      "location": "São Paulo, SP",
      "description": "Gatinho carinhoso e brincalhão",
      "photos": ["url1.jpg", "url2.jpg"]
    }
POST /api/cats

Cria um novo anúncio de doação

Parâmetros:

name (string) obrigatório

Nome do gatinho

age (string) obrigatório

Idade do gatinho

sex (string) obrigatório

Sexo (Macho/Fêmea)

color (string) obrigatório

Cor do gatinho

description (string) obrigatório

Descrição do gatinho

location (string) obrigatório

Localização do gatinho

contact (string) obrigatório

Contato

photo (string) opcional

Foto do gatinho

vaccinated ( boolean ) opcional

Filtrar por vacinação

neutered ( boolean ) opcional

Filtrar por castração

Resposta:

              
  {
    "name": "Miau",
    "age": "2 anos",
    "sex": "Macho",
    "color": "Laranja",
    "description": "Gatinho carinhoso e brincalhão",
    "location": "São Paulo, SP",
    "contact": "contato@lovecats.com",
    "vaccinated": true,
  }
PUT /api/cats/:id

Atualiza informações de um anúncio existente

Parâmetros:

id ( string ) obrigatório

ID único do gatinho

Resposta:

              
    {
      "success": "boolean",
      "message": "string",
      "data": "Cat"
    }
DELETE /api/cats/:id

Remove um anúncio de doação

Parâmetros:

id ( string ) obrigatório

ID único do gatinho

Resposta:

              
    {
      "success": "boolean",
      "message": "string"
    }

Exemplos de Código

Veja como integrar a API em diferentes linguagens 

// Buscar todos os gatinhos
fetch('https://api.lovecats.com/api/cats')
  .then(res => res.json())
  .then(data => console.log(data));

// Buscar com filtros
fetch('https://api.lovecats.com/api/cats?color=Laranja&vaccinated=true')
  .then(res => res.json())
  .then(data => console.log(data));

// Criar novo anúncio
fetch('https://api.lovecats.com/api/cats', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'X-API-Key': 'sua-chave-api'
  },
  body: JSON.stringify({
    name: 'Mel',
    age: '3 meses',
    sex: 'Fêmea',
    color: 'Laranja',
    description: 'Gatinha super carinhosa',
    location: 'São Paulo, SP',
    contact: '11999999999',
    vaccinated: true,
    neutered: false
  })
})
.then(res => res.json())
.then(data => console.log(data));
import requests

# Buscar todos os gatinhos
response = requests.get('https://api.lovecats.com/api/cats')
cats = response.json()

# Buscar com filtros
params = {'color': 'Laranja', 'vaccinated': True}
response = requests.get('https://api.lovecats.com/api/cats', params=params)
cats = response.json()

# Criar novo anúncio
headers = {
    'Content-Type': 'application/json',
    'X-API-Key': 'sua-chave-api'
}
data = {
    'name': 'Mel',
    'age': '3 meses',
    'sex': 'Fêmea',
    'color': 'Laranja',
    'description': 'Gatinha super carinhosa',
    'location': 'São Paulo, SP',
    'contact': '11999999999',
    'vaccinated': True,
    'neutered': False
}
response = requests.post('https://api.lovecats.com/api/cats', 
                        json=data, headers=headers)
result = response.json()
# Buscar todos os gatinhos
curl https://api.lovecats.com/api/cats

# Buscar com filtros
curl "https://api.lovecats.com/api/cats?color=Laranja&vaccinated=true"

# Criar novo anúncio
curl -X POST https://api.lovecats.com/api/cats \
  -H "Content-Type: application/json" \
  -H "X-API-Key: sua-chave-api" \
  -d '{
    "name": "Mel",
    "age": "3 meses",
    "sex": "Fêmea",
    "color": "Laranja",
    "description": "Gatinha super carinhosa",
    "location": "São Paulo, SP",
    "contact": "11999999999",
    "vaccinated": true,
    "neutered": false
  }'
