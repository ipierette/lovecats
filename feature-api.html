Endpoints Disponíveis

Todos os endpoints retornam dados em formato JSON

GET /api/cats

Lista todos os gatinhos disponíveis para adoção

Parâmetros:

color (string) opcional

Filtrar por cor

sex (string) opcional

Filtrar por sexo (Macho/Fêmea)

age (string) opcional

Filtrar por idade

vaccinated (boolean) opcional

Filtrar por vacinação

neutered (boolean) opcional

Filtrar por castração

Resposta:

{
  "id": "string",
  "name": "string",
  "age": "string",
  "sex": "Macho | Fêmea",
  "color": "string",
  "description": "string",
  "location": "string",
  "contact": "string",
  "photo": "string",
  "vaccinated": "boolean",
  "neutered": "boolean"
}
