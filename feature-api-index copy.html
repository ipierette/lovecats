Endpoints Disponíveis

Todos os endpoints retornam dados em formato JSON

GET /api/cats

Lista todos os gatinhos disponíveis para adoção

Parâmetros:

color (string)Filtrar por cor — opcional
sex (string)Filtrar por sexo (Macho/Fêmea) — opcional
age (string)Filtrar por idade — opcional
vaccinated (boolean)Filtrar por vacinação — opcional
neutered (boolean)Filtrar por castração — opcional

Resposta:

{
  "id": "string",
  "name": "string",
  "age": "string",
  "sex": "Macho | Fêmea",
  "color": "string",
  "description": "string",
  "location": "string",
  "contact": "string",
  "photo": "string",
  "vaccinated": "boolean",
  "neutered": "boolean"
}
